# Pingus Expansion

## Description

This is an expansion of [Adriano Petrucci's Pingus desktop pet](https://github.com/Adrianotiger/desktopPet/tree/master/Pets/pingus).

Their version was presumably inspired by [XPenguins](http://xpenguins.seul.org/) (or [WinPenguins](https://winpenguins.sourceforge.io/)), and this expansion just adds more stuff. If you want a more faithful recreation of XPenguins, but for 64-bit Windows, check out [WinPenguins by Ricky65](https://github.com/ricky65/WinPenguins) (or just be cool and get a Linux operating system)



Play Pingus here: [https://pingus.seul.org/](https://pingus.seul.org/)



## Additions

* Restored screen climbing - now the Pingus can waltz up the side of the screen again, and even fly around afterwards! (This was restored from Adriano's version)
* Improved falling and imported the splat animation
* The 3 digging animations now actually dig
* You can explode them... (double right-click)
* Other tweaks to make the Pingus feel more polished and lively, without being too distracting
